WHAT THE APP IS
---------------
Local-first (Mac/MLX) + hosted (OpenCode) creator pipeline for the Star Wars
fan series "Gravedancer to General": structured random seed → outline →
day-by-day novella → visual prompts, with a Textual TUI driving parallel
local/remote runs, live stage-tree progress, and browser previews.

THE 40K-TOKENS-PER-DAY LEVER
----------------------------
Daily output = chapters/day × SECTION_MAX_TOKENS. Current: 5 × 4500 = 22.5k
tokens/day on local MLX (memory-bound ceiling). For hosted runs the TUI now
auto-sets GRAVEDANCER_SECTION_MAX_TOKENS=12000 → 5 × 12000 = 60k tokens/day
headroom (target is ~45k). Tunables:
  GRAVEDANCER_DAILY_TARGET_TOKENS   (default 45000 → drives word targets)
  GRAVEDANCER_SECTION_MAX_TOKENS    (default 4500; TUI forces 12000 on OpenCode)
  GRAVEDANCER_OPENCODE_STALL        (default 600s no-output → kill)
  GRAVEDANCER_OPENCODE_TIMEOUT      (default 1800s overall → kill)
Continuity tunables (story-together):
  GRAVEDANCER_STORY_SO_FAR          (default on; "0"/"false"/"off" disables)
  GRAVEDANCER_STORY_SO_FAR_MAX_CHARS(default 8000 cap on injected digest)
  GRAVEDANCER_SECTION_TAIL_CHARS    (default 1800; TUI forces 4000 on OpenCode)
NOTE: free-tier endpoints may still stall/rate-limit at this volume. For real
production runs use gpt-5.6-luna (~$0.40/episode) — fast and reliable.

ROADMAP (priority order)
────────────────────────────────────────────────────────────────────
1. VALIDATE LUNA END-TO-END                             [on hold 2026-08-21]
   DECISION: hosted validation only via ox-alpha-free; luna/local descoped.
   ox-alpha-free measured at production scale and it cannot: the real outline
   prompt (3.3k chars) drives `opencode run` into a 5-step agent tool-loop
   (~18k injected context tokens/step, 432 output tokens) with ZERO visible
   text — outline returns empty. --agent plan stalls >6 min. Small prompts
   answer fine, so smoke-scale works; production length does not.
   Evidence: log/oxalpha-free-validation-seed42.log
   Revisit if the free tier improves or the $10 workspace limit is raised
   (luna command preserved in KNOWN ISSUES below). Story-together (#2) is
   already covered by 12 unit tests; live validation deferred indefinitely.

2. STORY-TOGETHER UPGRADE (pipeline-side continuity)        [done 2026-08-21]
   Shipped: generate_day_recap() at each day boundary (temp 0.2, ≤700 tok),
   digest injected as **STORY SO FAR** into every section prompt (capped
   ~8000 chars, newest kept); recaps stored in checkpoints + session state;
   GRAVEDANCER_SECTION_TAIL_CHARS (default 1800, TUI forces 4000 hosted).
   Recap failure degrades gracefully to tail-only continuity.

3. PER-DAY MODEL ROUTING
   We already route per-run. Next: per-stage models (outline on strongest

KNOWN ISSUES / WATCH ITEMS
--------------------------
• ON HOLD (2026-08-21, per decision): hosted production validation runs are
  descoped unless ox-alpha-free can handle them — it cannot at production
  length (see ROADMAP #1 for measurements). If limits ever get raised and a
  luna run is wanted:
    GRAVEDANCER_SECTION_MAX_TOKENS=12000 GRAVEDANCER_SECTION_TAIL_CHARS=4000 \
    venv/bin/python run_creative_pipeline.py --seed 42 \
      --model opencode:opencode-go/gpt-5.6-luna 2>&1 | tee log/luna-validation-seed42.log
  (seed 42 = The Ashen Chain → direct quality comparison vs the v3 demo)
• ox-alpha-free quirk: `opencode run` injects ~17-18k context tokens even for
  tiny prompts; at outline-prompt size the model tool-loops and emits no text.
  Free tier is smoke-scale only.
• OpenCode CLI emits API errors as JSON on STDOUT; mlx_client now parses
  error events and surfaces the real message instead of "OpenCode run failed".
• Free-tier OpenCode endpoints stall under sustained volume — watchdog now
  converts this to an error in ≤10 min, but production runs should use paid
  cheap models (luna).
• opencode CLI ignores temperature/top_p/max_tokens entirely (provider-bound).
• LM Studio + rapid-mlx share port 1234 by default — don't run both servers
  simultaneously without moving one.
• tests/test_session_state asserts current defaults (fixed); keep in sync
  when DEFAULT_MODEL changes again.
• Streamlit shell still works but TUI is now the primary interface; Streamlit
  tabs duplicate keyframe rendering (tab_art/tab_viewer) — consolidate if the
  web shell stays.
